# 🏥 Medical Report Analyzer AI

An AI-powered application that analyzes medical report PDFs and provides simplified health insights using Large Language Models (LLMs) and NLP-based analysis.

## Features

- Upload medical reports in PDF format
- Extract text from medical documents
- Analyze reports using LLMs
- Detect abnormal medical values
- Identify possible health conditions
- Generate health risk score
- Provide AI-generated summary and recommendations

## Tech Stack

- Python
- Streamlit
- FastAPI
- Large Language Models (LLMs)
- pdfplumber
- NLP

## How It Works

1. User uploads a medical report PDF.
2. The system extracts text from the report.
3. Extracted information is analyzed using an LLM.
4. The application generates a summary, detects abnormalities, and provides recommendations.

## Disclaimer

This application provides AI-generated insights for educational purposes and is not a substitute for professional medical advice.
